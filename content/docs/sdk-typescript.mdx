`@rallya/sdk` — zero runtime dependencies, fetch-based (works in Node 18+,
browsers, edge runtimes), full types generated from the live Swagger spec.
[npm](https://www.npmjs.com/package/@rallya/sdk) ·
[GitHub](https://github.com/nikhea/rallya-js-sdk)

```bash
npm i @rallya/sdk
```

```ts
import { RallyaClient } from "@rallya/sdk";
```

Use `@rallya/sdk/node` only for the Stripe webhook verifier — browser builds
must import `@rallya/sdk`.

## Client construction

Exactly one auth mode — both together (or neither) throws at construction:

```ts
// 1. User sessions (browser/mobile): short-lived JWT + refresh rotation
let tokens: TokenPair | null = null;
const client = new RallyaClient({
  baseUrl: "http://localhost:8080/api/v1",
  getTokens: () => tokens,
  setTokens: (t) => { tokens = t; },
  onAuthFailure: () => { /* refresh rejected — signed out */ },
});

// 2. Server-to-server org keys (rk_live_*): no refresh cycle
const server = new RallyaClient({
  baseUrl: "http://localhost:8080/api/v1",
  apiKey: process.env.RALLYA_API_KEY,        // static string …
  // apiKey: () => vault.read("rallya/key"), // … or async provider
});
```

| Option | Notes |
|---|---|
| `baseUrl` | Required. `http://localhost:8080/api/v1` in dev. Trailing slashes are stripped. |
| `getTokens` / `setTokens` | Required together for session mode. May be async. |
| `apiKey` | Static string or `() => string \| null \| Promise<string \| null>`. |
| `onAuthFailure` | Fires on dead session/key (refresh rejected, 401 after retry). Client clears stored tokens first. |
| `fetchImpl` | Custom fetch for edge runtimes, tests, instrumentation. Defaults to global `fetch`. |

UUID-or-slug segments are escaped for you (`RallyaClient.seg`).

## Behavior notes (both modes)

- **401 → refresh → retry** (session mode, single-flight): concurrent 401s
  trigger one refresh; the retried request uses the rotated pair. Refresh
  rejected (401/404) → `setTokens(null)` + `onAuthFailure()`.
- **API-key mode**: `X-API-Key` header, no refresh, no token store. A 401
  fires `onAuthFailure` directly.
- **Idempotency**: `orders.create` auto-generates an `idempotencyKey` when
  omitted; pass your own to make retries converge across processes.
- **Uploads**: covers/images enforce a 5 MB cap client-side (throws before
  the request). `Buffer` inputs are sent as `application/octet-stream`.
- **Pagination**: list routes take `{ page?, perPage? }` (server defaults
  1/20, max 100). The server sometimes omits `page`/`perPage` on the wire;
  the SDK backfills them from your request (`withPage`), so `Page<T>` always
  has `items`, `total`, `page`, `perPage`.
- **Batch check-in**: `checkin.scanBatch` rejects more than 50 codes locally
  (server also caps at 50 → 413).
- **`health.live()`** resolves against the **origin** of `baseUrl` (it sits
  outside `/api/v1`), no auth.
- **Public routes** (`listPublic`, `getPublic`, `listPlans`, verify/reset
  flows) send no auth header.

## Resources

All methods return promises; every API failure throws `RallyaError`.

## Errors

Every API failure throws `RallyaError`:

| Field / getter | Meaning |
|---|---|
| `status` | HTTP status |
| `code?` | Machine code (`EMAIL_NOT_VERIFIED`, `UPGRADE_REQUIRED`, …) |
| `message` | Server `{error}` text |
| `details?` | Full parsed body when present |
| `retryAfterMs?` | Parsed `Retry-After` (429 only) |
| `isUnauthorized` / `isForbidden` / `isNotFound` / `isRateLimited` | Convenience getters |

Stealth 404s mean "not found **or** no access" — use the helper:

```ts
import { RallyaError, isNotFoundOrForbidden } from "@rallya/sdk";

try {
  await client.orgs.get("acme");
} catch (e) {
  if (isNotFoundOrForbidden(e)) { /* missing or no access */ }
  if (e instanceof RallyaError && e.isRateLimited) await sleep(e.retryAfterMs ?? 1000);
}
```

## Core types

`TokenPair` `{accessToken, refreshToken}` · `Page<T>` `{items, total, page, perPage}` ·
`PageQuery` `{page?, perPage?}` · `MemberRole` `OWNER|ADMIN|MEMBER` ·
`EventStatus` `DRAFT|PUBLISHED|CANCELLED` · `TicketStatus` `DRAFT|ACTIVE|PAUSED` ·
`OrderStatus` `PENDING|PENDING_PAYMENT|CONFIRMED|CANCELLED|EXPIRED` ·
`AttendeeStatus` `REGISTERED|CHECKED_IN|CANCELLED` ·
`CheckinOutcome` `CHECKED_IN|ALREADY_CHECKED_IN|INVALID_CODE|CANCELLED|WRONG_EVENT|REVERTED` ·
`CollectionStatus` `PENDING|COLLECTED|VOIDED` ·
`SubscriptionPlan` `FREE|PRO|SCALE` · `SubscriptionStatus` `ACTIVE|PAST_DUE|CANCELED` ·
`PlanLimits` `{maxEvents, maxMembers, maxAttendeesPerEvent, maxKitsPerEvent}` ·
`PolicyDiff` `{added, removed, total}` — see [Schemas](/docs/schemas) for the
full wire shapes and [Swagger](/docs/swagger) for machine truth.

## Stripe webhooks (`@rallya/sdk/node`)

Node-only. Verify over the **raw** body — frameworks must not JSON-parse first:

```ts
import { verifyStripeWebhookSignature } from "@rallya/sdk/node";

const { verified, eventId } = verifyStripeWebhookSignature({
  rawBody,               // string | Buffer, untouched
  signatureHeader: req.headers["stripe-signature"],
  webhookSecret: process.env.STRIPE_WEBHOOKS_SIGNING_SECRET!,
  toleranceSecs: 300,    // optional, default 300
});
if (!verified) return res.status(400).end();
```

## Development

```bash
npm run gen        # ../rallya/docs/swagger.json → openapi3.json → src/generated/schema.ts
npm run gen:check  # fail if the committed schema drifted from swagger.json
npm test           # vitest
npm run build      # tsup → dist/
```

`src/generated/schema.ts` (~7,800 lines) is generated, never hand-edited.
The hand-friendly `src/types.ts` mirrors it 1:1; wire truth is the generated
schema. See [Swagger & OpenAPI](/docs/swagger) for the pipeline.
