`*` = required. Timestamps are RFC 3339 strings. IDs are UUIDs unless a route
documents UUID-or-slug. Field lists below were regenerated from
`rallya/docs/swagger.json` (99 definitions, `swag init` output) — package
prefixes match between spec and Go code (`dto.` auth, `orgdto.` orgs, …).
Machine truth: [Swagger & OpenAPI](/docs/swagger), `/swagger/index.html`.

Type notation: `string`, `int`, `bool`, `datetime`, `[]T` array,
`→Name` = `$ref` to another definition in this index.

## Cross-cutting

**Error envelope** — `{error}` or `{error, code?}` (`dto.ErrorResponse`).
Billing codes: `UPGRADE_REQUIRED` (402), `BILLING_UNAVAILABLE` (503),
`ALREADY_SUBSCRIBED` (409), `INVALID_PLAN` (400). Auth code:
`EMAIL_NOT_VERIFIED` (403). Rate limits (429) carry `Retry-After`.

**Page** — every `*Page` is `{items[], total, page, perPage}` with server
defaults 1/20 and max 100 per page. Both SDKs backfill `page`/`perPage`
from the request when a route omits them.

## Subscriptions (`subdto.*`)

```
subdto.TierResponse           currency, features: []string, limits: →Limits,
                              monthlyCents, name, plan, priceId
subdto.Limits                 maxAttendeesPerEvent, maxEvents, maxKitsPerEvent, maxMembers
subdto.SubscriptionResponse   cancelAtPeriodEnd, currentPeriodEnd, plan, status
subdto.CheckoutRequest        plan: string   (PRO | SCALE)
subdto.CheckoutResponse       sessionId: string, url: string

subdto.ErrorAlias             error: string, code: string
```

`plan`: `FREE | PRO | SCALE` · `status`: `ACTIVE | PAST_DUE | CANCELED`.
Limits use `-1` = unlimited, `0` = disabled. Free: 3/5/200/0. Pro: 25/25/2000/10.
Scale: 200/200/20000/−1. Absent subscription reads FREE/ACTIVE.

## Full inventory

That is all 99 definitions: 15 auth (`dto`) + 24 orgs (`orgdto`) + 8 events
(`eventdto`) + 6 tickets (`ticketdto`) + 4 orders + 3 payments (`orderdto`,
`paymentdto`) + 5 attendees (`attendeedto`) + 7 check-in (`checkindto`) + 7 kits
(`kitdto`) + 7 subscriptions (`subdto`) + 3 audit (`auditdto`) + 10 admin
(`admindto`). The spec flattens everything into `#/definitions`, so definition
names are package-prefixed — unique package names per domain are what make
that namespace collision-free (see [Architecture](/docs/architecture)).

Code samples typed against these definitions are in the
[TypeScript SDK](/docs/sdk-typescript) and [Go SDK](/docs/sdk-go) references.
