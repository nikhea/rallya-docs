## Client construction

Exactly one auth mode — both together, or neither, is a construction error:

```go
// 1. User sessions (short-lived JWT + refresh rotation)
store := rallya.NewMemoryTokenStore(nil) // or your own storage
client, err := rallya.NewClient(rallya.Options{
    BaseURL:   "http://localhost:8080/api/v1",
    GetTokens: store.GetTokens,   // func() *rallya.TokenPair
    SetTokens: store.SetTokens,   // func(*rallya.TokenPair)
    OnAuthFailure: func() { /* refresh rejected — signed out */ },
})

// 2. Server-to-server org keys (rk_live_*): no refresh cycle
client, err = rallya.NewClient(rallya.Options{
    BaseURL: "http://localhost:8080/api/v1",
    APIKey:  os.Getenv("RALLYA_API_KEY"),          // static …
    // APIKeyFunc: func() string { return vault.Read("rallya/key") }, // … or provider
})
```

| Option | Notes |
|---|---|
| `BaseURL` | Required. Trailing slashes are tolerated. |
| `GetTokens` / `SetTokens` | Required together for session mode. |
| `APIKey` / `APIKeyFunc` | Static org key or provider func. |
| `OnAuthFailure` | Fires on dead session/key; the client clears stored tokens first. |
| `HTTPClient` | Injectable transport (tests, proxies, tracing). Defaults to `http.DefaultClient`. |

`rallya.Seg` path-escapes UUID-or-slug segments; `client.BaseURL` may carry a
trailing slash.

## Behavior notes

- **401 → refresh → retry** (session mode, single-flight): one refresh for
  concurrent 401s; reused refresh tokens rotate server-side.
- **API-key mode**: `X-API-Key` header, no refresh. 401 fires `OnAuthFailure`.
- **Idempotency**: `Orders.Create` auto-generates an idempotency key when
  `CreateOrderInput.IdempotencyKey` is empty.
- **Uploads**: covers/images take `[]byte` + filename + content type
  (multipart), enforced server-side at 5 MB.
- **Pagination**: list routes take `*PageQuery` (server defaults 1/20, max
  100); the server echoes `page`/`perPage` on every page envelope. The SDK
  backfills them from your request (`FillPage`) so `Page[T]` always carries
  `Items`, `Total`, `Page`, `PerPage`.
- **Batch check-in**: `ScanBatch` rejects more than 50 codes locally.
- **`Health.Live`** resolves against the **origin** of `BaseURL` (outside
  `/api/v1`), no auth.
- **Public routes** (`ListPublic`, `GetPublic`, `ListPlans`, auth flows) send
  no auth header.

## Errors

Every API failure returns `*rallya.RallyaError`:

| Field / helper | Meaning |
|---|---|
| `Status` | HTTP status |
| `Code` | Machine code (`EMAIL_NOT_VERIFIED`, `UPGRADE_REQUIRED`, …) |
| `Message` | Server `{error}` text |
| `Details` | Full parsed body when present |
| `RetryAfterMs` | Parsed `Retry-After` in ms (429 only) |
| `IsUnauthorized()` / `IsForbidden()` / `IsNotFound()` / `IsRateLimited()` | Convenience helpers |
| `rallya.IsNotFoundOrForbidden(err)` | 404/403 stealth helper |

```go
_, err = client.Orgs.Get(ctx, "acme")
var re *rallya.RallyaError
if errors.As(err, &re) && re.IsRateLimited() {
    time.Sleep(time.Duration(*re.RetryAfterMs) * time.Millisecond)
}
if rallya.IsNotFoundOrForbidden(err) { /* missing or no access */ }
```

## Stripe webhooks (`webhooks` package)

Stdlib-only HMAC verification over the **raw** body — handlers must not JSON-parse first:

```go
res := webhooks.VerifySignature(rawBody, r.Header.Get("Stripe-Signature"),
    os.Getenv("STRIPE_WEBHOOK_SIGNING_SECRET"))
if !res.Verified { /* 400 */ }
_ = res.EventID
```

`VerifySignature(rawBody []byte, signatureHeader, webhookSecret string, toleranceSecs ...int)` — default tolerance 300s.
